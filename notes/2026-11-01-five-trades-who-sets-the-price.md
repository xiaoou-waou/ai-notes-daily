## 一、今日观察

今天六件事，表面上是三条不相干的线：DeepSeek 开源了一个 Agent 底座、商汤开源了一个 9B 模型、苹果把 Siri 交给了千问、OpenAI 融资缩水、Google 从太空收回一首诗、DeepSeek 的搜索接口开始收钱。

把它们翻译成同一句话：**每一件都是一笔"用过剩的资源换稀缺的资源"的交易。** 区分它们的不是换了什么，而是**这笔交易由谁来定价**。

| 想换到的稀缺物 | 付出的代价 | 谁在做 | 成交了吗 | 定价方 |
|---|---|---|---|---|
| **人的注意力** | 读缓存 token 从 605 万涨到 **2323 万**（约 3.8 倍） | DeepSeek Super-agent | ✅ p95 从 **29.5 分钟**降到 **15.7 分钟** | 自己（合成负载可复跑） |
| **显存里的参数** | 每次前向从 32 次层计算变成 **56 次** | 商汤 SenseNova Loop-9B | ✅ **9B** 存储对标 27B 级 | 自己（Apache-2.0，可下载复测） |
| **系统级入口** | 把 Siri / 写作工具 / 视觉智能交给第三方模型 | Apple × 阿里千问 | ✅ 11-4 起 Beta，12 月随 iOS 27.3 正式 | 监管 + 用户（可关闭、承诺不训练） |
| **明天的算力** | 估值从 1.4 万亿降到 **1.25 万亿**美元 | OpenAI | ⚠️ 融资目标 300→**200 亿**美元，首轮交割预计不足额 | 外部投资者（纳斯达克100 周五 **−3.5%**） |
| **轨道上的电** | 一颗卫星（4 颗 TPU，一次只能开 1 颗、约 **20 分钟**） | Google Suncatcher | ⚠️ 换到一首 20 token 的诗 | 物理定律（官方自评 2035 年前不具成本优势） |
| **（昨天还免费的）网页检索** | **¥5 / 千次，今天 00:00 起** | 每个用 DeepSeek 的 agent | — | DeepSeek 官方定价页 |

前三行之所以顺利成交，有一个共同点：**付出的那一项能被精确计量，换来的那一项能当场测出来。** 分钟数、benchmark、能不能在真机上跑通——都是当天就能拿到答案的东西。

下面两行卡住，原因也只有一个：**付出是确定的，收益要等三年后由别人来估。** OpenAI 的估值不是 OpenAI 定的，Google 的发射成本不在 Google 手里——它们被迫把定价权交出去，然后被砍了一刀。

最后一行是这条规律最朴素的证明：**没有价格的东西会被默认成便宜，一旦标价，套利空间立刻收缩。** 今天零点，很多人的 agent 成本模型里多了一行他们从没算过的账。

### 1. 🟢 DeepSeek 开源 Super-agent 原型：一份带分母的"token 换时间"汇率
10 月 31 日晚，DeepSeek Harness 团队发布《Super-agent 设计探索：迈向更自主的 Agent 系统》，同步开源原型 `github.com/deepseek-ai/dsh-superagent-prototype`（**MIT**，首提交 2026-10-31）。README 开宗明义：**"Research prototype for reference only, not an official DeepSeek product."** 哲学写在 `docs/000-philosophy.md`：**"Take as little human attention as possible, and give as much value as possible."**

架构是 Router + Worker 两层：常驻 Router 承接人类交互与全局分派、**不亲自执行任务**（甚至可以不配 Bash，用轻量模型即可）；上下文隔离的 Worker 并发执行，不直接对人说话，统一向 Router 汇报。另有事件驱动（两级过滤 Fast/Slow Path）、订阅与直通、Inline & Spill + 链式召回、投机执行、计算/状态/环境分离 + 端侧 daemon、外部 Watchdog 五个模块。

**最值钱的是那张四行对照表**（合成负载：约 300 条消息、约 20 条工作请求，每种方案跑 **5 次**，消息间隔与工作时长按 1/4 缩放，编码任务用"只消耗时间的工具"替代）：

| 方案 | 任务完成时间 p50 / p95（分钟） | 全部 Session 读缓存 token |
|---|---|---|
| Super-agent | **12.4 / 15.7** | **2323 万** |
| Super-agent，去掉订阅直通 | 12.6 / 15.5 | **3177 万** |
| 单 Session + Subagent（中性提示） | 20.4 / **29.5** | 605 万 |
| 单 Session + Subagent（提示优先委派） | 13.8 / 29.0 | 1082 万 |

**关键在读法**：去掉"订阅直通"后，完成时间**几乎没变**（12.4/15.7 → 12.6/15.5），但 Router 决策次数增加约 **30%**、读缓存 token 涨 **37%**（2323 万 → 3177 万）。也就是说——**直通机制省的是钱，不是时间。** 另外，Router 压测显示：Trigger 从约 1 条/分钟升到 40 条/分钟时，平均 batch 从 1.0 涨到 2.8，单次请求耗时 2.5s→3.9s，但**单个决定分摊的推理时间从 6.4s 降到 1.6s**。

> ⚠️ 信源说明：**仓库 README（MIT、research prototype 定位、哲学原句、目录结构）已直连核实**。上表实验数字引自官方技术文章，经智东西、机智流、通信世界、环球网等多家一致转述，未能直连官方文章原文。团队自述实验"基于合成负载与简化环境，是初步参考，不是正式产品结论"。

### 2. 🟢 商汤开源 SenseNova Loop-9B-Preview：把"循环深度"从论文搬进了 pip
10 月 30 日，商汤开源 `sensenova/SenseNova-Loop-9B-Preview`（HF）与 `OpenSenseNova/SenseNova-Loop`（GitHub），**Apache-2.0**。核心是 Looped Transformer：**32 个独立解码层**，中间循环段 `[4, 28)` 共享权重跑 **2 遍**，因此每次前向执行 **56 次层计算**；磁盘上存约 **9B** 参数，推理实际参与计算约 **14.6B**。

规格：训练上下文最长 **262,144 token（256K）**；文本+图像输入、文本输出；隐藏维度 4,096 / FFN 12,288 / 词表 248,320 / 16 头 & 4 KV 头（GQA）；混合注意力（每 4 层一组，**3 层线性 + 1 层全注意力**，循环边界与完整组对齐）；主干 BF16，但 **mHC 路由参数刻意保留 FP32**（官方提醒别统一量化成低精度）。

mHC（流形约束超连接）消融，官方口径：**GPQA Diamond +4.42 分、TeamBench +13.34 分**。

部署要点：`transformers==5.18.0` + PyTorch 2.11.0（CUDA 13.0），**必须 `trust_remote_code=True`**（自定义实现）；LightLLM、SGLang 均有路径；**MTP 加速可用，Dspark / Dflash2 官方标注"仍在训练"**；技术报告状态为 **TBD**（未发布）。官方明确定位"长上下文与智能体工作流"，并自承"跨月长期记忆仍是开放问题"。

## 三、为什么值得记

1. **"多花 token 省时间"第一次有了带分母的报价。** DeepSeek 那四行表是全篇最硬的东西：p95 从 29.5 分钟降到 15.7 分钟，代价是读缓存 token 从 605 万涨到 2323 万。**这不是"agent 更快了"，这是第一次有人把汇率摆到台面上**——你可以拿自己任务的 token 账单去除以节省的时间，得出你自己的汇率，再决定要不要上多 agent。在此之前，这类架构决策全靠体感。

2. **"订阅直通省的是钱不是时间"是被官方自己的消融实验背书的。** 去掉直通，时间几乎不变（12.4/15.7 vs 12.6/15.5），token 涨 37%、Router 决策涨 30%。这条比任何"多 agent 架构最佳实践"都有用：**当你的 agent 系统卡在成本而不是延迟时，先去看"后续事件是不是都绕了一圈中央节点"，而不是急着换更强的模型。**

3. **资本侧第一次出现明确的"抢不到钱"信号，而且原因跟技术无关。** OpenAI 估值砍 10.7%、融资目标砍 33%，Anthropic 估值预期从 2 万亿降到 1.5 万亿，两边争抢的是**同一批机构投资者**。这与 DeepSeek 说的"一个人只能同时跟进 3–5 个活跃会话"是同一个瓶颈的两种形态：**投资人的注意力也只有一份。** 工程侧的解法是加一层 Router 帮人分派；资本侧没有 Router，只能靠降价。

4. **最危险的成本项，从来不是你在付费的那一项，是你从没算过、某天开始计费的那一项。** DeepSeek 的 Search/Fetch 从今天零点起 ¥5/千次，波及所有在 Claude Code / Codex / Harness 里通过 Server 端工具调用白用搜索的人。这类"隐性免费→显性收费"的转折，在 agent 成本模型里比模型涨价难防得多，因为它不在你的账单列里，只在你的调用日志里。

5. **"参数不够用计算补"从论文变成了可以 `pip install` 的东西。** Loop-9B 的意义不在"9B 打 27B"（那是厂商自测，且优势集中在办公/PPT/agent 类多步骤任务），而在于它把架构创新的验证门槛从"发论文"降到了"发权重"。**代价同样明确：56 次层计算意味着延迟账没人替你算，官方只说 MTP 可用、两个投机解码方案还在训练。**
