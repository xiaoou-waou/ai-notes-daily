## 三、为什么值得记

**一、"更强"要问在哪一段。** 三个旋钮的边际收益完全不是一个量级：数据覆盖率从 1% 到 100% 是 50 个百分点的跃迁，循环从 2 圈到 4 圈是 1 个百分点，推理努力对正确率是不显著。选型时真正该问的不是"哪个模型更强"，而是"我的瓶颈落在哪条曲线的哪一段"——落错段，投入就是纯浪费。

**二、置信度是模型最便宜的输出，也是最不该直接采信的。** 名义 95%、实际覆盖 20–62%，这个差距不是"偶尔不准"，而是**系统性高估**。更值得注意的是两个反直觉细节：把区间要宽没用（模型会照旧报窄区间），而让它把策略说出来，区间分数能提高 1.6–2.5 倍、覆盖率却几乎不动——说明模型能"讲得像那么回事"，但这套叙述与它是否真的知道，是两件事。

**三、错误是共享的，"多模型投票"在系统性盲区上会一起错。** 购物 Agent 那篇最该被工程团队记住的一条：多个模型不仅同错，还倾向于选**同一个错商品**。这意味着投票、集成、交叉验证这些兜底手段，在"大家都缺同一块知识"的场景里等于没有兜底——而这恰恰是模型最容易自信的地方。

**四、制度侧已经先承认了自我报告不可信。** 工信部选择造四维刻度，而不是要求厂商"更自信地声明能力"；这条路径对做 agent 的人同样成立：可交付的应该是**证据字段**（数据从哪来、怎么复算、哪一步是估的），而不是一个 0 到 1 的 confidence。

## 五、术语卡

| 术语 | 解释 |
| :--- | :--- |
| **循环 Transformer（Looped Transformer）** | 让同一组层在一个前向里被执行多次，输出回灌自身，用"多算几遍"换计算深度，而不增加存储的参数量。 |
| **推理等效参数（inference-equivalent parameters）** | 厂商为便于横向比较给出的折算口径：把重复执行的层计算按"相当于多少参数的一次前向"折算。Loop-9B 约 9B 存参、约 14.6B 等效。 |
| **校准（calibration）与覆盖率（coverage）** | 校准指"声明的把握"与"实际正确率"是否吻合；覆盖率指模型给出的 95% 区间真正包含真值的比例。名义 95%、实际 20–62% 即严重失校准。 |
| **推理努力（reasoning effort）** | 推理时可调的思考预算（思考 token 上限、采样轮次等）。本文两篇论文的共同发现：它显著抬升置信度，未必抬升正确率。 |
| **智能化能力分级（L0–L5）** | SJ/T 12355—2026 定义的人形机器人能力刻度，按感知认知、决策学习、执行表现、协作交互四维评定，并以雷达图 + 基础等级 + 综合等级三层表达。 |
