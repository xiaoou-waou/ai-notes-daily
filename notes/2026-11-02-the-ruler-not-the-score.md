## 一、今日观察

今天翻完一圈，最值得记的不是哪条新闻最大，而是一个反常的共性：**没有一家在宣布"我更强"，六件事全都在改"怎么算"。**

模型能力这条轴今天几乎没人碰。所有人动的都是旁边的东西——准入资格、质量维度、验收口径、计费单位、分发中立性。这些是"尺子"。尺子一动，原来排在第一名的东西不一定还排第一。

| 原来用什么量 | 今天换成什么 | 谁换的 | 换完之后谁占便宜 |
|---|---|---|---|
| 模型谁跑分高 | 谁能在中国合法落地（备案 + 本地模型） | 苹果 × 阿里 | 有备案与本地化通道的一方 |
| 数据有多少万小时 | **8 维质量指标** + 有效信息密度 | YD/T 6771—2026（11-1 实施） | 有质检体系、能稳定交付的供方 |
| 模型跑多少分 | **单位算力产出**（平台工程五环节） | 信通院系列标准（首批 11-1 实施） | 有全生命周期工程能力的平台方 |
| 代码还原得像不像 | **能不能重编译跑通**（差分测试） | 上海交大 × MiniMax | 有验证积累、能跑测试的一方 |
| 订阅能发多少次 | **token** | OpenAI（12 月起） | 卖复杂 agent 任务的一方 |
| 开源分发中是否中立 | 会不会变成歧视性杠杆 | 美国司法部（问询中） | **还没定**——唯一一把没换完的尺子 |

注意最后一列：前五把尺子换完，受益方都是"有流程、有验证、有工程体系"的一方，不是"模型最聪明"的一方。这不是巧合。当能力趋同，竞争就会自动下沉到"谁经得起被度量"。

而最后一行是今天唯一还没落地的：**司法部问的是权力度量，不是技术度量**，这类尺子换得最慢，也最难被工程手段应对。

### 2. 🟢 具身智能数据集质量标准今日实施，"小时数"不再自动成立

**YD/T 6771—2026《人工智能 关键基础技术 具身智能数据集质量要求及评价方法》**由工信部于 **2026 年 7 月 24 日批准发布**，中国信通院联合**40 余家**单位起草，**2026 年 11 月 1 日正式实施**。

- 8 项质量评价指标：**完整性、一致性、多样性、真实性、易用性、实用性、可扩展性、安全性**
- 内容三块：数据生产全流程规范（采集/清洗/标注/存储）、组织机制保障（人员/培训/审核/安全合规）、可量化评价指标
- 信通院具身智能机器人部副主任张蔚敏的定性："标准的意义只是为了尽快地让大家降低试错成本"

这条最狠的一刀砍在**估值口径**上：数据不能只凭"小时数"或"样本量"定价，竞争单位正从"数据规模"切换为**有效信息密度 × 任务难度 × 闭环增益**。

### 4. 🟢 上海交大用 MiniMax 做"软件再工程"，5000 个核心函数全部开源

在 2026 世界顶尖科学家论坛人工智能平行论坛（11 月 1 日上海临港闭幕）上，上海交通大学特聘教授、**IEEE Fellow 孔令和**团队发布国内首个大模型原生的软件逆向成果。

- 规模：一套美国仿真软件主体 **3 万个函数**，团队已完成其中 **5000 个核心函数**的再工程，功能不变、性能相当；**代码、说明书、测试用例全部开源**
- 方法三步：**① 读懂意图**（改模型本身，使其能对核心逻辑做语义分析，从"认得代码"到"能推断变量含义、结构布局、分支缘由"）→ **② 生成式重构**（摸清设计目的后重写一套，顺手砍冗余、提速、补漏洞）→ **③ 交叉质检**（多个独立 AI 智能体分头核对逻辑、跑新旧版本差分测试、专门找漏洞）
- 模型选型：在海内外多款文本模型上验证后，最终用 **MiniMax** 落地，理由是其在逆向分析、逻辑恢复类网络安全能力上表现突出

**真正的观点在这里**：学术圈正在形成的共识是，评价标准从"像不像源码"换成"**能不能跑**"——即"可重执行率"（反编译出来的代码能否重新编译并通过原始测试断言）。这一步把幻觉挡在了门外。而工业软件的壁垒，也正从"代码保密"退回到"**验证**"：算法是几十年攒的，代码可以读懂，但缺了几十年的实验数据对照，仿真结果照样不敢用。

## 三、为什么值得记

1. **"能不能合法落地"第一次压过了"谁更强"。** 苹果选 Qwen 不看跑分，看的是备案状态与中国本地可用性——网信办 7 月才完成 7 项端侧生成式 AI 服务备案，Apple Intelligence 就在其中。这意味着国产模型出海之外多了一条更宽的路：**被跨国巨头按市场选用**。反过来，所有想在中国区上系统级 AI 的硬件厂商，现在都有了一个可抄的模板。

2. **标准不干预能力，只干预"作用于哪个变量"——这才是它的杀伤力。** 这批标准没有一条规定模型要跑多少分，它们规定的是数据处理、训练、推理、调度、运维五个环节怎么被度量，以及数据要用 8 个维度打分。竞争变量被从"模型跑分"搬到"单位算力产出"和"有效信息密度"，**跑分型选手的护城河一夜之间不被承认了**。

3. **"可重执行率"是把幻觉挡在门外的那道闸。** 上海交大这套方法的价值不在"逆向了工业软件"，而在于它把验收标准从"像不像源码"（字节级一致）换成了"能不能重编译、能不能通过原始测试断言"。这是可以照搬到任何代码生成流水线里的一条：**不要比代码相似度，要比能否重编译跑通**。而它同时指出了天花板——壁垒会从"代码保密"退到"验证"，后者才是真正难追的部分。

4. **默认档位是一种隐性的定价权。** OpenAI 把额度单位换成 token、Moonshot 把 `reasoning_effort` 默认设成 max，两件事是同一种操作：**厂商替用户做了成本决定，且这个决定写在默认值里**。用户以为自己在选模型，其实在选一个没人解释过的档位。这是接下来两年最容易吃亏的地方。

5. **唯一没换完的尺子，恰恰是最难应对的那把。** 前五把尺子都能靠工程手段适应（做质检体系、建验证流程、固定 effort 档位），但司法部问的是"分发平台会不会变成歧视性杠杆"——这是权力结构的度量，企业没有对应的技术动作，只能等结果。把所有开源模型供应链押在单一枢纽上的团队，现在应该开始想 Plan B。

## 四、可行动

- [ ] **查一遍自己有没有 pinned 到 `kimi-k2*` 或 `moonshot-v1`**：若有，先在 staging key 上换成 `kimi-k3.1-pro`，并**显式设置 `reasoning_effort`**（建议：agent 循环与编码用 high，路由/打标/短摘要用 low，max 只留给硬问题），同时**一个会话内不要切档**（会失效 prefix cache）。改完对比"每任务成本"，而不是"每 token 价格"。
- [ ] **给代码生成流水线加一道"可重执行"闸门**：不比对源码相似度，改为"重新编译 + 跑通原有测试断言"，再加一个差分测试（新旧版本对同一组输入给同样输出）。这一步能挡住绝大部分幻觉型改动。
- [ ] **用 token 而不是"次数"重估 12 月后的 OpenAI 账单**：先统计现有 Work / Codex 复杂任务的 token 分布，识别出最贵的那一档任务，判断它是否值得留在合并后的共享额度里。Instant chat 不占额度，把轻量对话迁过去是白捡的。
- [ ] **如果你在做具身智能相关的数据采购或交付**：把合同里的验收口径从"小时数 / 样本量"改成 YD/T 6771—2026 的 8 维（完整性、一致性、多样性、真实性、易用性、实用性、可扩展性、安全性），尤其是"真实性"——它直接决定了仿真数据能不能顶替真机数据。
- [ ] **给开源模型供应链做一次单点故障排查**：列出你依赖 Hugging Face 的具体环节（权重下载、数据集、Space 演示、CI 拉取），评估若枢纽归属变化后的替代路径（ModelScope、镜像自建、vendor 直连）。司法部问询结果未定，但排查成本很低。

## 五、术语卡

| 术语 | 解释 | 为什么今天重要 |
|---|---|---|
| **MoE / 激活参数** | 混合专家架构中，总参数量很大但每个 token 只唤醒其中一小部分。因此"模型多大"要区分总参数与激活参数两个口径 | 阿里 Qwen4 架构预览（Qwen3.8-Flash-Next）为 **125B 总参数 / 每 token 激活 6B**，训练资源约为 Qwen3.7-Plus 的 **1/9**——参数规模这把尺子正在被激活参数取代（🟡 厂商披露值，见[凤凰网科技](https://tech.ifeng.com/c/8xfVyoqWRSE)） |
| **可重执行率** | 反编译/重构出的代码能否重新编译并通过原始测试断言的比率 | 上海交大验收用的是差分测试而非"字节级一致"，这是把幻觉挡在门外的关键指标 |
| **差分测试** | 对同一组输入，比较新旧两个版本输出是否一致，用于验证重构未改变行为 | 工业界认可的验证方式，但前提是你能跑原版——闭源软件授权协议通常禁止逆向 |
| **prefix cache（前缀缓存）** | 对提示词前缀的 KV 缓存复用，命中时显著省 token | K3.1 Pro 文档中明确：切换 reasoning_effort 档位会使 prefix cache 命中失效 → 档位要按会话固定 |
| **reasoning_effort** | 推理强度档位（如 low / high / max），决定模型在给出可见答案前生成多少思考 token | Moonshot K3.1 Pro 默认 **max** 且无法关闭 thinking；只改模型名不改档位，等于让厂商替你决定账单 |
